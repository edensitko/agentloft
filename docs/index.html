You hold the penNothing in the office can answer a session or approve a permission for you.

Download it and walk in

  1. Download
    git clone https://github.com/edensitko/agentloft.git
  2. Start it
    cd agentloft; npm install; npm start
  3. Walk in

    Open localhost:4455 on the same computer and pick your office. This site has no login and no way into anyone's office, yours included.

macOS, or Windows and Linux (experimental). You need Node.js 22 or newer, and Claude Code.

Before you move in

Does it use my Claude tokens?

No. It reads files that are already on your computer and never talks to a model.

Does it work on Windows or Linux?

Yes, as an experiment. The server is tested on both, but the notifications and the links to the Claude app have only been used on a Mac so far.
